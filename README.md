# Opportune
A web application that turns an opportunity link into an actionable plan, helping users avoid missed applications, forgotten deadlines, and last-minute submissions.


The problem:
Imagine finding a fully funded scholarship on LinkedIn while you are in class. You copy the link, tell yourself you will apply in the evening, and forget about it. Three weeks later, the deadline has passed.
Your application should make that process almost automatic:
Paste the link.
AI reads the opportunity and extracts the important details.
The system saves it to your dashboard.
The user receives reminders before the deadline.
The system helps the user take the next step instead of merely storing a link.

Objectives: 
To develop an AI-assisted web application that extracts, organizes, prioritizes, and tracks opportunities from user-provided links, while providing proactive deadline reminders and application planning.
This is a credible portfolio project because it combines frontend development, backend APIs, data extraction, AI integration, scheduled background tasks, authentication, and external service integration.
